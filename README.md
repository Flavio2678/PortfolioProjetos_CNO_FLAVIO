## Projetos

### 📐 App de Álgebra Relacional

Aplicação interativa para praticar as operações da álgebra relacional: seleção (σ),
projeção (π), união (∪), interseção (∩), diferença (−), produto cartesiano (×),
junção natural (⋈) e renomeação (ρ). Inclui um explorador de operadores, tabelas de
exemplo (`Alunos`, `Cursos`, `Matrículas`) e exercícios com correção automática.

- **Arquivo:** [`App_matematica relacional`](App_matematica%20relacional) — página única em HTML/CSS/JS
- **Pré-visualizar:** [abrir via htmlpreview.github.io](https://htmlpreview.github.io/?https://github.com/Flavio2678/PortfolioProjetos_CNO_FLAVIO/blob/main/App_matematica%20relacional)

  > Se a pré-visualização não renderizar, renomeie o arquivo para `algebra-relacional.html`
  > e ative o GitHub Pages em *Settings → Pages* para publicar uma URL própria.
